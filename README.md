## Overview

AIR Hybrid combines multi-sample playback with a three-oscillator virtual analog engine, processing both through shared filters, modulators, and effects to blend the warmth of samples with synthesized texture.

Whether you're a newcomer just getting started or a seasoned pro looking for advanced tools, **AIR Hybrid** delivers the features you need in a clean, intuitive package.

## Key Features

| Feature | Description |
|---------|-------------|
| **Sample Engine** | Multi-sample playback with velocity switching and loop control |
| **VA Oscillators** | Three virtual analog oscillators with classic waveform shapes |
| **Shared Filter** | Combined filter processing for both engines with LP, HP, and BP modes |
| **Effect Chain** | Integrated chorus, delay, and reverb effects for the combined output |
